#  Como Executar o Projeto

### 1. Criar o ambiente virtual
```bash
python -m venv venv
```

### 2. Ativar o ambiente virtual
```bash
.\venv\Scripts\activate
```

### 3. Instalar as dependências
```bash
pip install -r requirements.txt
```

### 4. Rodar a aplicação
```bash
uvicorn main:app --reload
```
